# O Vazio: Convergência

Card game autoral em desenvolvimento. Este repositório será utilizado para reunir o **Editor de Cartas**, a **Coleção**, a **Montagem de Decks** e o **Campo de Duelo** em uma aplicação web.

## Estado atual (22/11/2026)

- Repositório conectado e branch `main` acessível.
- **Editor de Cartas v5** identificado na biblioteca do projeto: `Editor_de_Cartas_O_Vazio_Completo_v5.html`.
- **Campo jogável v1** identificado na biblioteca: `O_Vazio_Campo_Jogavel_HTML_v1.html`.
- A transferência dos HTMLs completos da biblioteca para o ambiente de publicação **não foi autorizada pelo serviço de arquivos**. Portanto, o código dos dois aplicativos **ainda não foi publicado aqui**.
- Este repositório **não contém uma versão jogável publicada** neste momento.

## Restrições de preservação

1. Nunca substituir as molduras, artes, símbolos ou layouts aprovados por imagens semelhantes ou recriações.
2. Manter **elemento** e **moldura** como configurações distintas.
3. Preservar os oito elementos: Água, Fogo, Luz, Trevas, Vento, Terra, Trovão e Gelo.
4. Campos de texto devem respeitar os limites físicos da carta; preservar opções de fonte, tamanho e cor.
5. Não alterar regras pendentes como se estivessem confirmadas.
6. Não descartar arquivos originais do editor e do campo para simplificar a implantação.
